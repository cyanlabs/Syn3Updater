## Syn3 Updater 3.0: rebuilt for Windows, macOS and Linux

Syn3 Updater has been rewritten from the ground up. It still prepares the same USB drives with the same install files, and now works the same way on every system.

## New
- **Windows, macOS and Linux.** One app on .NET 10 and Avalonia (v2 was Windows only). Windows zip (x64, ARM64), macOS DMG (Apple Silicon and Intel, macOS 14 or newer), and on Linux a .deb, .rpm, Arch package and a tar.gz installer (x64 and ARM64).
- **A redesigned app.** A labelled sidebar, a guided 1-2-3 Home page with an always-visible Start bar, a live download queue, light, dark or system theme, and settings that save when you leave the tab.
- **Automatic updates.** The app checks for new releases on your channel (Stable or Beta) and only installs a release whose signature checks out. Windows installs and the Linux tar.gz install update in place; deb, rpm and Arch installs show the exact command to run.
- **Diagnostics.** One page checks the tools and permissions your system needs, your folders, the API key, the CyanLabs and Ford servers and the clock, and says how to fix anything that fails. Copy the report to ask for help.
- **Logs you can share.** Logs start with a system section and replace your home folder with ~. The Logs tab lists, searches and uploads them.
- **Crash reports, only if you agree.** After a crash, the next start offers to send a report, with an optional comment. Nothing is sent unless you say yes.
- **Clear connection problems.** A red "No connection to CyanLabs" banner, and messages that say what to check, with a button for the status page.

## Safer installs
- **The install mode is chosen for you.** AutoInstall, Reformat or Downgrade comes from your version, maps and MY20 setting by a fixed set of rules, never a guess. While MY20 isn't known, Home shows MY20 Check and asks before it does anything that could damage a unit. Maps that can't be used on your unit (ESN locked) are marked and blocked. The rules: https://github.com/CyanLabs/Syn3Updater/blob/main/docs/install-mode-logic.md
- **Install files that match v2.** autoinstall.lst and reformat.lst are checked in tests against real files written by v2, for Reformat, Downgrade (including to Sync 3.3.19052), installs with and without maps, and every utility. The only differences are small and deliberate: every line reads "Open1 = ..." with the same spacing, and a downgrade to Sync 3.3.19052 lists the apps file once in reformat.lst, not twice.
- **Required tool files are visible.** The package list shows the files Reformat and Downgrade add (the reformat tool, RW data cleaner, downgrade app and tool) as locked rows, so the counts and sizes match what is downloaded.
- **A clearer Interrogator.** The log reader gives a clearer result, and treats a log with no model as MY20, the safe choice.

## Downloads and drives
- **Faster, safer downloads.** Several connections at once (you choose how many in Settings), interrupted downloads resume, every file is checksum-checked, and free space is checked before anything is downloaded or erased. Files are written as .part and only renamed when complete.
- **Pick a USB drive or any folder.** Download Only, an Eject button, and the download location shown on Home and Downloads. While a job runs, the other pages are locked and ejecting is refused.

## Also in 3.0
- **All the utilities.** Gracenotes removal, the small voice package, enforced downgrade, the RW data cleaner and the log-reading USB. Upgrade to 2.2 is now implemented (in v2 the button was an empty stub).
- **Profiles with their own Generator Key,** which unlocks the private releases and maps made for that key.
- **Your v2 settings carry over.** Install mode, MY20 and download connections are read as they were.
- **syn3updater:// links** from the CyanLabs website and forum open the app with the region, release and maps already chosen.
- **30 languages.**
- **Coming from v2 on Windows:** the v2 Launcher updates you to 3.0, your shortcuts and the link handler move to the new app, and files that old versions left behind are removed.

## Good to know
- **Windows** asks for Administrator rights (it needs them to format USB drives). The app isn't code-signed, so SmartScreen may warn: choose More info, then Run anyway.
- **macOS:** the app is signed ad hoc, not notarised. The first time, right-click it and choose Open. Updates open the download page instead of installing in place.
- **Linux has had the most testing on real hardware.** The Windows and macOS drive code is covered by tests but less proven on real devices, so please report problems: https://github.com/CyanLabs/Syn3Updater/issues
